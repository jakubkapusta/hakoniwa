# Hakoniwa 箱庭

Kartonowe dioramy z Japonii do złożenia kawałek po kawałku, jak japońskie zestawy modelarskie z papieru. Kładziesz kawałki z arkusza na ich zarysy, siatki same się zaginają, a po ostatnim kawałku zapada wieczór i miniatura ożywa.

- **Yatai z ramenem:** stoisko pod kwitnącą sakurą, miasteczko i góra w tle.
- **Przystanek w deszczu:** wiejska wiata między polami ryżowymi, przyjeżdża autobus, latają świetliki.

W każdej scence ukrywa się sekret do znalezienia po finale.

Grafika i dźwięk są w całości generowane w kodzie (canvas, Web Audio). Gra działa offline jako PWA.

```bash
npm install
npm run dev
```
